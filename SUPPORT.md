# Support Policy

## Community Support Channels

We offer community-based support through the following official channels:

### 1. Documentation & Architecture Guides
Before opening an issue, review the comprehensive documentation available in [`docs/`](./docs):
- [**Quickstart Guide**](./docs/quickstart.md): Zero to your first AEAD encryption in 5 minutes.
- [**Architecture Guide**](./docs/architecture.md): Complete system decomposition and Mermaid state/sequence diagrams.
- [**Cookbook (Practical Recipes)**](./docs/cookbook.md): End-to-end security problem and solution guides.
- [**Public API Reference**](./docs/api-reference.md): Formal Microsoft Learn-style documentation for all public contracts.
- [**Migration from DataProtection**](./docs/migration-from-dataprotection.md): Zero-downtime migration from `Microsoft.AspNetCore.DataProtection`.
- [**Migration from ASP.NET Identity PasswordHasher**](./docs/migration-from-identity-passwordhasher.md): Transparent rehash migration guide.

### 2. GitHub Discussions
Use GitHub Discussions for:
- Architecture and design pattern inquiries.
- Integration questions with custom databases, cloud providers, or frameworks.
- Feature requests and conceptual feedback.

### 3. Issue Tracker
Use the GitHub Issue Tracker for:
- Verified functional bugs and regressions with minimal reproduction steps.
- Performance regressions verified against BenchmarkDotNet.
- Build or Native AOT compilation errors.

> [!IMPORTANT]
> **Security Vulnerabilities**:
> Do NOT open public issues for security vulnerabilities. Report all suspected vulnerabilities privately to **`ericksonlopezf@gmail.com`** per our [Security Policy](./SECURITY.md).
